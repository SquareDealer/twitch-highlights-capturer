# Ручная проверка

Автоматические тесты покрывают логику и HTTP API. Всё, что зависит от настоящего Twitch, браузера, Windows и аккаунта Google, проверяется здесь. Отмечайте результат каждого пункта.

## Просмотр и запись

1. [ ] `start.cmd` (или `npm start`) — открывается браузер на `http://localhost:3717`. Ввести живой канал, «Смотреть». Плеер Twitch показывает эфир, без ошибки о параметре `parent`.
2. [ ] Через 5–10 секунд статус `LIVE`; счётчик «Буфер» растёт до `05:00` и останавливается.
3. [ ] Кликнуть по плееру (фокус уходит внутрь плеера), нажать `2` — появляется поле «Новый маркер» с таймкодом, эфир не останавливается.
4. [ ] Набрать комментарий с цифрами — цифры попадают в текст, новые маркеры не создаются. `Enter` — счётчик «1 маркер».
5. [ ] `3`, затем `Esc` — маркер удалён, счётчик не изменился.
6. [ ] Курсор в поле «Канал», нажать `5` — цифра печатается в поле, маркер не создаётся.
7. [ ] `F8` — через ~5 секунд уведомление «Черновик сохранён».

## Редактор и сохранение

8. [ ] `F9` — открывается редактор, превью воспроизводится, маркеры стоят на таймлайне. Оценить, насколько маркер совпадает с моментом нажатия; при стабильном сдвиге поправить «Ручной сдвиг маркеров».
9. [ ] Сдвинуть ручки обрезки, перетащить маркер, изменить комментарий, ввести название «Funny reaction», `Ctrl+S`.
10. [ ] Возврат к просмотру, «0 маркеров». Через несколько секунд в `Видео\TwitchHighlights\<канал>\<начало названия стрима>_<дата>\<дата>_funny-reaction_<xxxx>\` лежат `funny-reaction.mp4` и `markers.json`; таймкоды в JSON совпадают с положением маркеров в клипе.
11. [ ] Маркер, поставленный сразу после `Ctrl+S`, остаётся в счётчике после завершения экспорта.
12. [ ] Название с символами `<>:"/\|?*` и кириллицей — клип сохраняется, папка создаётся.

## Устойчивость

13. [ ] Отключить сеть на 20 секунд во время записи: статус «Переподключение…», затем снова `LIVE`. Маркер до разрыва и маркер после — `F8` после разрыва даёт черновик только со вторым; первый помечен «вне черновика».
14. [ ] Поставить маркер, подождать 7 минут, остановить приложение `Ctrl+C` в терминале. После запуска в «Библиотеке» есть черновик с этим маркером.
15. [ ] Остановить приложение (`Ctrl+C`) во время сохранения клипа — после запуска экспорт завершается (клип появляется в «Библиотеке»).
16. [ ] Убрать `streamlink` из `PATH` — при «Смотреть» понятная ошибка в статусе.
17. [ ] Запустить приложение второй раз — в терминале сообщение, что порт занят, и открывается вкладка уже запущенного приложения.
18. [ ] Остановить сервер при открытой вкладке — появляется «Нет связи с приложением»; запустить снова — плашка исчезает сама, статус и маркеры на месте.
19. [ ] Открыть `http://127.0.0.1:3717` — адрес меняется на `localhost`, плеер работает.

## Google Drive

20. [ ] Ввести Client ID / Secret, «Подключить», выдать доступ в открывшейся вкладке Google — статус «Подключено: <email>».
21. [ ] Сохранить клип — через несколько секунд в Drive `TwitchHighlights/<канал>/<эфир>/<клип>/` с двумя файлами, статус «В облаке».
22. [ ] Отключить сеть, сохранить клип — статус «Ожидает»; включить сеть — загрузка проходит сама (до ~1 минуты) либо по кнопке «Синхронизировать».
23. [ ] «Синхронизировать всё» повторно — дубликатов в Drive нет.
24. [ ] Остановить приложение посреди загрузки — после запуска загрузка возобновляется.
