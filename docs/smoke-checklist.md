# Ручная проверка на Windows

Автоматические тесты покрывают логику, а сквозной сценарий проверен на синтетическом потоке под Linux. Всё, что зависит от настоящего Twitch, Windows и аккаунта Google, проверяется здесь. Отмечайте результат каждого пункта.

## Просмотр и запись

1. [ ] `npm run dev`, ввести живой канал, «Смотреть». Плеер Twitch показывает эфир со звуком, без ошибки о параметре `parent`.
2. [ ] Через 5–10 секунд статус `LIVE`; счётчик «Буфер» растёт до `05:00` и останавливается.
3. [ ] Кликнуть по плееру (фокус уходит внутрь плеера), нажать `2` — появляется поле «Новый маркер» с таймкодом, эфир не останавливается.
4. [ ] Набрать комментарий с цифрами — цифры попадают в текст, новые маркеры не создаются. `Enter` — счётчик «1 маркер».
5. [ ] `3`, затем `Esc` — маркер удалён, счётчик не изменился.
6. [ ] Курсор в поле «Канал», нажать `5` — цифра печатается в поле, маркер не создаётся.
7. [ ] `F8` — через ~5 секунд уведомление «Черновик сохранён».

## Редактор и сохранение

8. [ ] `F9` — открывается редактор, превью воспроизводится, маркеры стоят на таймлайне. Оценить, насколько маркер совпадает с моментом нажатия; при стабильном сдвиге поправить «Ручной сдвиг маркеров».
9. [ ] Сдвинуть ручки обрезки, перетащить маркер, изменить комментарий, ввести название «Funny reaction», `Ctrl+S`.
10. [ ] Возврат к просмотру, «0 маркеров». Через несколько секунд в `Видео\TwitchHighlights\<канал>\<id>_<дата>\<дата>_funny-reaction_<xxxx>\` лежат `funny-reaction.mp4` и `markers.json`; таймкоды в JSON совпадают с положением маркеров в клипе.
11. [ ] Маркер, поставленный сразу после `Ctrl+S`, остаётся в счётчике после завершения экспорта.
12. [ ] Название с символами `<>:"/\|?*` и кириллицей — клип сохраняется, папка создаётся.

## Устойчивость

13. [ ] Отключить сеть на 20 секунд во время записи: статус «Переподключение…», затем снова `LIVE`. Маркер до разрыва и маркер после — `F8` после разрыва даёт черновик только со вторым; первый помечен «вне черновика».
14. [ ] Поставить маркер, подождать 7 минут, закрыть приложение. После запуска в «Библиотеке» есть черновик с этим маркером.
15. [ ] Закрыть приложение во время сохранения клипа — после запуска экспорт завершается (клип появляется в «Библиотеке»).
16. [ ] Убрать `streamlink` из `PATH` — при «Смотреть» понятная ошибка в статусе.
17. [ ] Запустить приложение второй раз — фокус получает уже открытое окно.

## Google Drive

18. [ ] Ввести Client ID / Secret, «Подключить», выдать доступ в браузере — статус «Подключено: <email>».
19. [ ] Сохранить клип — через несколько секунд в Drive `TwitchHighlights/<канал>/<эфир>/<клип>/` с двумя файлами, статус «В облаке».
20. [ ] Отключить сеть, сохранить клип — статус «Ожидает»; включить сеть — загрузка проходит сама (до ~1 минуты) либо по кнопке «Синхронизировать».
21. [ ] «Синхронизировать всё» повторно — дубликатов в Drive нет.
22. [ ] Закрыть приложение посреди загрузки — после запуска загрузка возобновляется.

## Установщик

23. [ ] `npm run dist` — в `dist/` появляется установщик; установленное приложение запускается и проходит пункты 1–3.
