# Twitch Highlight Recorder

Windows-приложение для нарезки моментов из прямых эфиров Twitch. Вы смотрите один канал через официальный плеер Twitch, приложение параллельно пишет последние 5 минут эфира в кольцевой буфер. Цифрами `1`–`9` ставятся маркеры, `F8` сохраняет повтор, в редакторе клип обрезается и сохраняется как MP4 + `markers.json`, после чего уходит в Google Drive.

## Что нужно установить

- Windows 10/11 x64, Node.js 22+ (только для сборки из исходников).
- Streamlink и FFmpeg — они не входят в установщик:

```bash
winget install streamlink
```

```bash
winget install Gyan.FFmpeg
```

Если программы не в `PATH`, укажите полные пути в «Настройках».

## Запуск и сборка

```bash
npm install
```

```bash
npm run dev
```

```bash
npm test
```

```bash
npm run dist
```

`npm run dist` собирает установщик в `dist/` (запускать на Windows).

## Клавиши

| Клавиша | Где работает | Что делает |
| --- | --- | --- |
| `1`–`9` | экран «Просмотр», курсор не в текстовом поле | Маркер типа 1–9. Время фиксируется в момент нажатия; затем можно ввести комментарий и нажать `Enter` (можно пустой). `Esc` удаляет маркер. |
| `F8` | «Просмотр», «Редактор» | Сохранить в черновик последние 180 секунд и ещё 5 секунд после нажатия. |
| `F9` | «Просмотр», «Редактор» | Открыть или закрыть редактор. Если черновика ещё нет — сначала делается `F8`. |
| `Ctrl+S` | «Редактор» | Сохранить клип: MP4 и `markers.json`. Активный набор маркеров очищается. |

Клавиши действуют только когда окно приложения в фокусе.

## Как это устроено

- Маркер закрепляет в буфере 30 секунд до и 60 секунд после себя — эти сегменты не удаляются, пока клип не сохранён или маркеры не сброшены.
- `Ctrl+S` сразу открывает новый набор маркеров: всё, что вы поставите во время экспорта, относится уже к следующему клипу. Если экспорт не удался, клип остаётся в «Библиотека → Не сохранены» и его можно сохранить повторно.
- При остановке записи и при выходе из несохранённых маркеров автоматически собирается черновик.
- Сырые сегменты буфера не переживают перезапуск; черновики и клипы — переживают.
- Клипы лежат в `Видео\TwitchHighlights\<канал>\<id эфира>_<дата>\<дата>_<название>_<xxxx>\`.

## Точность маркеров

Плеер Twitch и запись получают эфир независимо, поэтому время маркера оценивается: момент нажатия минус разница задержек плеера и записи. Если маркеры в редакторе стабильно стоят раньше или позже нужного момента, поправьте «Ручной сдвиг маркеров» в настройках (отрицательное значение — раньше). Точную позицию всегда можно выставить в редакторе перетаскиванием или кнопкой «⌖».

## Google Drive

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **Google Drive API** и создайте OAuth-клиент типа **Desktop app**.
2. Вставьте Client ID и Client Secret в «Настройки» и нажмите «Подключить» — откроется браузер.
3. После сохранения клип загружается в `TwitchHighlights/<канал>/<эфир>/<клип>/` на Диске. При ошибке делается до 5 попыток с растущей паузой; дальше — кнопки «Синхронизировать» в «Библиотеке».

Приложение запрашивает доступ `drive.file`: оно видит только файлы, которые создало само. Токены хранятся в зашифрованном виде (Windows DPAPI).

## Сервис

Отдельный сервис без окна: записывает эфиры, сам находит моменты (всплеск чата, состоящий из смеха и реакций; громкий голос добавляет баллы) и нарезает клипы без перекодирования. Управление — через веб-интерфейс в браузере.

1. **Детектор (Python 3.10+).** В папке `detector`:
   ```
   python -m venv .venv
   .venv/Scripts/pip install -e .
   ```
   Скачайте модель `silero_vad.onnx` из репозитория snakers4/silero-vad (`src/silero_vad/data/silero_vad.onnx`) в `detector/models/silero_vad.onnx`. Подробности — `detector/README.md`.
2. **Веб-интерфейс:** `npm run service:build` (собирает `out/web`).
3. **Запуск:** `npm run service`. При первом запуске создаётся `config.json` со случайным паролем — он печатается в консоль один раз. Пути можно задать переменными `HL_CONFIG` (по умолчанию `./config.json`) и `HL_DATA` (по умолчанию `./data`: база, клипы, буфер).
4. **Профили и `config.json`.** Пороги детектора и параметры нарезки правятся во вкладке «Профили» веб-интерфейса. Значения из `config.json` используются один раз — при создании профиля «По умолчанию»; потом изменения этих ключей в файле не читаются. В `config.json` остаются общие настройки: порт (`port`, по умолчанию 8080), пароль, пути (`dataDir`, `libraryDir`, `bufferDir`, `streamlinkPath`, `ffmpegPath`, `pythonPath`), режим и лимит эфиров, размер буфера и сегмента, длина ручного клипа, резерв диска и сроки хранения. Если пакет детектора установлен в venv, укажите полный путь к его Python в `pythonPath`, например `"D:/proj/twitch-highlights-capturer/detector/.venv/Scripts/python.exe"` (Windows) или `.../detector/.venv/bin/python` (Linux); иначе установите пакет в тот `python`, что в `PATH`. Образец всех полей — `config.example.json`.
5. **Адрес:** `http://<ip-компьютера>:8080` из локальной сети, вход по паролю. Удалённый доступ — через туннель, например `cloudflared tunnel --url http://localhost:8080`.

**Правило автоклипа.** Клип создаётся, когда выполнены два условия подряд: чат ускорился не меньше чем в `minSpike` раз относительно своего фона (по умолчанию ×2), и не меньше `minTriggerShare` сообщений этого всплеска — смех или реакции (по умолчанию 50 %; минимум 3 сообщения от 2 авторов). Звук на срабатывание не влияет и только добавляет до 1 балла к оценке 1–10 (скорость — до 5, состав — до 3).

**Режим настройки.** Переключатель «Настройка» на карточке эфира показывает цепочку «всплеск → состав → звук» и графики скорости и состава за 5 минут. Порог на графике можно тянуть мышью, двигать стрелками или ввести числом: отметки показывают, какие пики сработали бы, а счётчик сравнивает с сохранёнными порогами. Идущий эфир меняется только после «Применить к профилю»; правка не перезапускает детектор и не сбрасывает его накопленное состояние.

**Google Drive (вкладка «Диск»).** Отобранные клипы («Беру») выгружаются на Google Drive кнопкой «Sync» в ленте — все сразу, независимо от фильтров, только MP4, прямо в выбранную папку (в имя файла добавляется канал). Настройка:

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **Google Drive API** и создайте OAuth-клиент типа **Web application**. В «Authorized redirect URIs» добавьте адрес возврата, который показывает вкладка «Диск» (для локального запуска — `http://localhost:8080/api/drive/callback`). Google принимает только `http://localhost` и адреса `https://` с доменом, поэтому интерфейс нужно открыть по такому адресу.
2. На экране согласия OAuth переведите приложение из «Testing» в «In production»: в статусе «Testing» вход слетает каждые 7 дней. Проверка Google для личного использования не нужна — при входе будет предупреждение «приложение не проверено».
3. Вставьте Client ID и Client Secret во вкладку «Диск», нажмите «Подключить Google Drive» и разрешите доступ. Сервис просит полный доступ к Диску (`drive`): только так можно писать в папку, созданную не им.
4. Выберите папку выгрузки: поиском по имени (по умолчанию `to_sort`) или ссылкой на папку.

Ключи хранятся в базе сервиса, токены — в `drive-token.json` в папке данных, без шифрования (как и пароль в `config.json`): берегите папку данных. Повторный «Sync» не создаёт дубликатов; неудачные выгрузки идут повторно при следующем нажатии. Снятие отметки «Беру» и смена папки файлы на Диске не трогают.

Остановка — Ctrl+C: незаконченные клипы дорезаются, затем сервис закрывается.

## Известные ограничения

- Чат Twitch не встроен: в окне только видео.
- Рекламные вставки Twitch попадают в запись и могут сдвигать оценку времени маркеров.
- При сохранении клип перекодируется (точная обрезка), поэтому сохранение занимает время и идёт в фоне.
- После переподключения к эфиру начинается новый отрезок записи: черновик не может включать видео по обе стороны разрыва.
- При превышении лимита временного хранилища (2 ГБ закреплённых сегментов) показывается предупреждение; автоматически закреплённое не удаляется.
