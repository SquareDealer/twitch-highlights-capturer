# Хайлайты Twitch — Realtime

Сервис без окна: записывает прямые эфиры Twitch, сам находит яркие моменты по чату и нарезает клипы. Управление — в браузере: запуск эфиров, лента клипов, настройка порогов, выгрузка отобранного на Google Drive.

> Это ветка `realtime`. Ручная нарезка моментов (маркеры, редактор) живёт отдельно — в ветке [`mvp-web`](../../tree/mvp-web).

## Как это работает

1. Вы даёте ссылку на канал. Сервис пишет эфир через Streamlink в кольцевой буфер на диске (последние 5 минут).
2. Детектор каждую секунду смотрит на чат и звук. Клип создаётся, когда выполнены два условия подряд:
   - **всплеск** — чат ускорился минимум в 2 раза относительно своего обычного темпа;
   - **состав** — не меньше половины сообщений этого всплеска — смех или реакции (и это минимум 3 сообщения от 2 авторов).
3. Громкий голос на срабатывание не влияет, но добавляет балл к оценке клипа (шкала 1–10).
4. Клип вырезается из буфера без перекодирования и появляется в ленте. Там его можно посмотреть, взять или отклонить.

Все числа настраиваются в интерфейсе, отдельно для разных каналов.

## Деплой на сервер

Нужен Linux-сервер с Docker и плагином Compose. Node.js, Python, Streamlink, FFmpeg и модель детектора уже в образе.

1. Скачайте проект и перейдите в его папку:

   ```bash
   git clone -b realtime https://github.com/SquareDealer/twitch-highlights-capturer.git highlights && cd highlights
   ```

2. Соберите и запустите (первая сборка занимает 10–15 минут):

   ```bash
   docker compose up -d --build
   ```

3. Узнайте пароль — он создаётся при первом запуске:

   ```bash
   docker compose logs highlights | grep "Пароль"
   ```

4. Откройте `http://<адрес-сервера>:8080` и войдите.

Что полезно знать:

- **Где что лежит.** Настройки — `config/config.json`, всё остальное (база, клипы, буфер) — `data/`. Обе папки создаются рядом с `docker-compose.yml` и переживают пересборку. Для резервной копии достаточно сохранить их.
- **Настройка.** Пароль, лимит эфиров, место под клипы — в [docs/CONFIG.md](docs/CONFIG.md). После правки файла: `docker compose restart`.
- **Обновление.** `git pull && docker compose up -d --build`.
- **Другой порт.** Создайте рядом файл `.env` со строкой `HL_PORT=9000`. Поле `port` в `config.json` при этом не меняйте.
- **HTTPS.** Сервис отдаёт обычный HTTP. Для доступа из интернета поставьте перед ним прокси с сертификатом, например `caddy reverse-proxy --from clips.example.com --to localhost:8080`. Для Google Drive это обязательно.
- **Остановка.** `docker compose down` — клипы, которые в этот момент нарезаются, дорезаются.

### Сколько нужно ресурсов

Видео не перекодируется, поэтому нагрузка небольшая. Замер на одном эфире 1080p60:

| Ресурс | 1 эфир | 5 эфиров (оценка) |
|---|---|---|
| Процессор | 6–7 % одного ядра | до половины ядра |
| Память | ~180 МБ | 0,6–0,8 ГБ |
| Видеокарта | не нужна | не нужна |
| Сеть (входящая) | ~8 Мбит/с | ~40 Мбит/с |
| Диск под буфер | ~290 МБ | ~1,5 ГБ |

Клипы занимают примерно 1 МБ на секунду видео. Сервис держит свободным резерв на диске (по умолчанию 10 ГБ) и ставит нарезку на паузу, если места меньше, — на маленьком диске уменьшите `diskReserveBytes`.

## Запуск на своём компьютере

Подходит для Windows, macOS и Linux. Нужны Node.js 22+, Python 3.10+, Streamlink и FFmpeg.

1. Установите программы:

   | Система | Команда |
   |---|---|
   | Windows | `winget install OpenJS.NodeJS.LTS Python.Python.3.12 streamlink Gyan.FFmpeg` |
   | macOS | `brew install node python streamlink ffmpeg` |
   | Ubuntu / Debian | `sudo apt install python3 python3-venv ffmpeg streamlink`, а Node.js 22+ — с [nodejs.org](https://nodejs.org/) |

2. Установите зависимости проекта и соберите интерфейс:

   ```bash
   npm install && npm run service:build
   ```

3. Подготовьте детектор. В папке `detector`:

   ```bash
   python -m venv .venv
   ```

   Затем установите пакет: на Windows — `.venv\Scripts\pip install -e .`, на macOS и Linux — `.venv/bin/pip install -e .`

   Скачайте модель [`silero_vad.onnx`](https://github.com/snakers4/silero-vad/raw/v5.1.2/src/silero_vad/data/silero_vad.onnx) в `detector/models/silero_vad.onnx`.

4. Запустите:

   ```bash
   npm start
   ```

   При первом запуске создаётся `config.json` со случайным паролем — он печатается в консоль один раз.

5. Укажите в `config.json` путь к Python детектора (`pythonPath`): `detector/.venv/Scripts/python.exe` на Windows или `detector/.venv/bin/python` на macOS и Linux — полным путём. Перезапустите сервис и откройте `http://localhost:8080`.

Остановка — Ctrl+C: незаконченные клипы дорезаются, затем сервис закрывается.

## Интерфейс

- **Эфиры.** Запуск записи по ссылке на канал, выбор качества и профиля, кнопка «Сохранить последние 60 с». Переключатель «Настройка» раскрывает панель: цепочка «Всплеск → Состав → Звук» и графики скорости и состава чата за 5 минут. Порог на графике можно тянуть мышью — отметки показывают, какие пики сработали бы. Эфир меняется только после «Применить к профилю».
- **Лента.** Клипы с оценкой и причиной срабатывания: «Беру», «Отклонить», «Скачать». Кнопка «Sync» выгружает все взятые клипы на Google Drive.
- **Профили.** Наборы порогов для разных каналов: шесть основных ручек с ползунками, остальное свёрнуто. Словари смеха и реакций, проверка «как детектор поймёт это сообщение».
- **Диск.** Подключение Google Drive и выбор папки выгрузки.

## Google Drive

Взятые клипы выгружаются кнопкой «Sync» в ленте — все сразу, только MP4, прямо в выбранную папку. Настройка на вкладке «Диск»:

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **Google Drive API** и создайте OAuth-клиент типа **Web application**. В «Authorized redirect URIs» добавьте адрес возврата, который показывает вкладка «Диск».
2. На экране согласия OAuth переведите приложение из «Testing» в «In production» — иначе вход слетает каждые 7 дней.
3. Вставьте Client ID и Client Secret, нажмите «Подключить Google Drive» и разрешите доступ.
4. Выберите папку: поиском по имени (по умолчанию `to_sort`) или ссылкой.

Google принимает вход только с адресов `http://localhost` и `https://` с доменом. Сервис просит полный доступ к Диску: только так можно писать в папку, которую создали вы. Токен хранится в папке данных без шифрования — берегите её.

## Для разработки

```bash
npm test
```

```bash
npm run typecheck
```

Тесты детектора — из папки `detector`: `.venv/Scripts/python -m pytest` (Windows) или `.venv/bin/python -m pytest`.

Устройство: `src/service` — сервис (HTTP, запись, нарезка, Drive), `src/web` — интерфейс, `src/main` — общие модули записи и базы, `detector` — детектор на Python. Проектные документы — в `docs/superpowers`, результаты ручных проверок — в `docs/smoke-checklist-service.md`.

## Известные ограничения

- Рекламные вставки Twitch попадают в запись.
- После переподключения к эфиру буфер начинается заново: клип не может включать видео по обе стороны разрыва.
- Клип режется без перекодирования, по границам кусочков записи: начало и конец точны до 2 секунд.
