# Twitch Highlight Recorder

Нарезка моментов из прямых эфиров Twitch прямо в браузере. Вы смотрите канал через официальный плеер Twitch, а приложение параллельно пишет последние 5 минут эфира в кольцевой буфер. Цифрами `1`–`9` ставятся маркеры, `F8` сохраняет повтор, в редакторе клип обрезается и сохраняется как MP4 + `markers.json`, после чего уходит в Google Drive.

Приложение работает у вас на компьютере: небольшой сервер на Node.js записывает эфир, а интерфейс открывается во вкладке браузера по адресу `http://localhost:3717`. Ничего, кроме Twitch и (по желанию) Google Drive, в интернет не уходит.

## Быстрый старт (Windows)

1. Установите Node.js, Streamlink и FFmpeg — по одной команде в терминале (PowerShell или «Командная строка»):

   ```bash
   winget install OpenJS.NodeJS.LTS
   ```

   ```bash
   winget install streamlink
   ```

   ```bash
   winget install Gyan.FFmpeg
   ```

   После установки закройте и заново откройте терминал, чтобы программы появились в `PATH`.

2. Скачайте проект: на GitHub — **Code → Download ZIP** и распакуйте, или через git:

   ```bash
   git clone https://github.com/SquareDealer/twitch-highlights-capturer.git
   ```

3. Дважды щёлкните **`start.cmd`** в папке проекта. При первом запуске он сам установит зависимости (около минуты), соберёт интерфейс и откроет браузер на `http://localhost:3717`.

4. Введите канал Twitch, нажмите «Смотреть» — запись в буфер начнётся автоматически.

Окно терминала, которое открыл `start.cmd`, — это и есть приложение: пока оно открыто, идёт запись. Чтобы выйти, нажмите в нём `Ctrl+C`: запись остановится, а несохранённые маркеры соберутся в черновик. Если просто закрыть окно, на это может не хватить времени.

### macOS и Linux

Установите Node.js 22+, Streamlink и FFmpeg пакетным менеджером (`brew install node streamlink ffmpeg` / `apt install …`), затем в папке проекта:

```bash
./start.sh
```

### Запуск вручную

То же самое, что делают `start.cmd` и `start.sh`:

```bash
npm install
```

```bash
npm start
```

`npm start` собирает интерфейс и запускает сервер. Если Streamlink или FFmpeg установлены не в `PATH`, укажите полные пути к ним в «Настройках» приложения.

## Настройка запуска

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `THR_PORT` | `3717` | Порт сервера. |
| `THR_DATA_DIR` | `%APPDATA%\twitch-highlight-recorder` (Windows), `~/Library/Application Support/twitch-highlight-recorder` (macOS), `~/.config/twitch-highlight-recorder` (Linux) | База, черновики и временный буфер. Это та же папка, что у прежней Electron-версии: её черновики и клипы подхватываются. |
| `THR_NO_OPEN` | — | `1` — не открывать браузер при старте. |

Пример для PowerShell: `$env:THR_PORT=3800; npm start`.

Открывайте приложение по адресу `http://localhost:…`, а не `127.0.0.1` — плеер Twitch работает только с `localhost` (по `127.0.0.1` сервер сам перенаправит). Держите приложение открытым в одной вкладке: в каждой вкладке свой плеер.

## Клавиши

| Клавиша | Где работает | Что делает |
| --- | --- | --- |
| `1`–`9` | экран «Просмотр», курсор не в текстовом поле | Маркер типа 1–9. Время фиксируется в момент нажатия; затем можно ввести комментарий и нажать `Enter` (можно пустой). `Esc` удаляет маркер. |
| `F8` | «Просмотр», «Редактор» | Сохранить в черновик последние 180 секунд и ещё 5 секунд после нажатия. |
| `F9` | «Просмотр», «Редактор» | Открыть или закрыть редактор. Если черновика ещё нет — сначала делается `F8`. |
| `Ctrl+S` | «Редактор» | Сохранить клип: MP4 и `markers.json`. Активный набор маркеров очищается. |

Клавиши работают, когда вкладка приложения активна. После клика по плееру фокус автоматически возвращается странице, поэтому маркеры можно ставить сразу (управление плеером с клавиатуры при этом недоступно — пользуйтесь мышью).

## Как это устроено

- Маркер закрепляет в буфере 30 секунд до и 60 секунд после себя — эти сегменты не удаляются, пока клип не сохранён или маркеры не сброшены.
- `Ctrl+S` сразу открывает новый набор маркеров: всё, что вы поставите во время экспорта, относится уже к следующему клипу. Если экспорт не удался, клип остаётся в «Библиотека → Не сохранены» и его можно сохранить повторно.
- При остановке записи и при выходе из приложения несохранённые маркеры автоматически собираются в черновик.
- Сырые сегменты буфера не переживают перезапуск; черновики и клипы — переживают.
- Клипы лежат в `Видео\TwitchHighlights\<канал>\<название стрима>_<дата>\<дата>_<название клипа>_<xxxx>\` (папку можно сменить в «Настройках»). Папка эфира называется по первым 40 символам названия стрима на момент начала записи; если названия нет — по id эфира.
- Если закрыть вкладку, запись продолжается — откройте `http://localhost:3717` снова. Если остановить сервер, страница покажет «Нет связи» и переподключится сама после запуска.

## Точность маркеров

Плеер Twitch и запись получают эфир независимо, поэтому время маркера оценивается: момент нажатия минус разница задержек плеера и записи. Если маркеры в редакторе стабильно стоят раньше или позже нужного момента, поправьте «Ручной сдвиг маркеров» в настройках (отрицательное значение — раньше). Точную позицию всегда можно выставить в редакторе перетаскиванием или кнопкой «⌖».

## Google Drive

1. В [Google Cloud Console](https://console.cloud.google.com/) создайте проект, включите **Google Drive API** и создайте OAuth-клиент типа **Desktop app**.
2. Вставьте Client ID и Client Secret в «Настройки» и нажмите «Подключить» — в браузере откроется вход в Google (если не открылся, ссылка есть в окне терминала).
3. После сохранения клип загружается в `TwitchHighlights/<канал>/<эфир>/<клип>/` на Диске. При ошибке делается до 5 попыток с растущей паузой; дальше — кнопки «Синхронизировать» в «Библиотеке».

Приложение запрашивает доступ `drive.file`: оно видит только файлы, которые создало само. Токены хранятся в папке данных в зашифрованном виде (AES-256-GCM, ключ — файл `drive-key.bin` рядом). Токены прежней Electron-версии перенести нельзя: после обновления нажмите «Подключить» ещё раз.

## Безопасность

Сервер слушает только `127.0.0.1`, поэтому с других компьютеров он недоступен. API принимает запросы только от страницы самого приложения: проверяются имя хоста (защита от DNS rebinding), `Origin` и тип содержимого, поэтому сторонние сайты и встроенный плеер Twitch вызвать его не могут. Client Secret от Google Drive в браузер не отдаётся.

## Разработка

```bash
npm run dev
```

Запускает сервер с перезапуском при изменениях (`tsx watch`) и Vite с горячей перезагрузкой интерфейса на `http://localhost:5173`; запросы `/api` и `/media` Vite передаёт серверу.

```bash
npm test
```

```bash
npm run typecheck
```

Структура:

- `src/server` — сервер: запись (Streamlink + FFmpeg), кольцевой буфер, маркеры, черновики, экспорт, Google Drive, HTTP API (`http.ts`, `rpc.ts`) и события по SSE (`events.ts`). Точка входа — `src/server/index.ts`.
- `src/web` — интерфейс на React; `api.ts` реализует `window.thr` поверх HTTP и SSE, `hotkeys.ts` — клавиши.
- `src/shared` — типы, список методов API, разбор клавиш.

Ручной сценарий проверки с настоящим Twitch и Google — в [`docs/smoke-checklist.md`](docs/smoke-checklist.md).

## Известные ограничения

- Чат Twitch не встроен: на странице только видео.
- Браузер может не дать плееру сразу включить звук — тогда кликните по плееру.
- Рекламные вставки Twitch попадают в запись и могут сдвигать оценку времени маркеров.
- При сохранении клип перекодируется (точная обрезка), поэтому сохранение занимает время и идёт в фоне.
- После переподключения к эфиру начинается новый отрезок записи: черновик не может включать видео по обе стороны разрыва.
- При превышении лимита временного хранилища (2 ГБ закреплённых сегментов) показывается предупреждение; автоматически закреплённое не удаляется.
